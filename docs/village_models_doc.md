## Проверенные параметры моделей

| Модель | Размер | Примечание |
|---|---|---|
| `wall` | 1×1×1 | Объёмная стена |
| `wall-pane` | 1×1×0 | Плоская стена, Pivot в центре основания |
| `wall-window` | 1×1×1 | Box Collider охватывает модель |
| `roof` | 1×1×1 | Pivot в центре основания |
| `roof-side` | 1×0.5×1 | Один скат, модель усечена с трёх сторон |
| `roof-side-corner` | 1×0.5×1 | Угловая модель, два ската вниз в стороны, две усечённые стороны |
| `roof-side-corner-inner` | 1×0.5×1 | Внутренний угловой элемент, скаты направлены внутрь и вниз |

### Общие правила набора

- Стандартные модели имеют размер `1×1×1`.
- Модели с суффиксом `-pane` имеют размер `1×1×0`.
- Модели совмещаются между собой.
- Стандартный Scale: `(1, 1, 1)`.
- Повторная проверка каждой стандартной модели не требуется.
- Модели с необычной геометрией проверяются отдельно.

Примечание: общие правила размеров основаны на проведённых проверках и наблюдениях при работе с набором. Не все модели проверялись индивидуально.

## Проверка соединений низкой кровельной группы

Для низкой кровельной группы проведена практическая проверка совместимости основных элементов.

### 1. Состав группы

**`roof-side`**

- Размер: `1×0.5×1`.
- Имеет один скат.
- Усечена с трёх сторон.
- Используется для формирования прямых участков низкой кровли.

**`roof-side-corner`**

- Размер: `1×0.5×1`.
- Угловая модель.
- Имеет два ската вниз в стороны.
- Две смежные стороны усечены.
- Используется для формирования внешних углов кровли.

**`roof-side-corner-inner`**

- Размер: `1×0.5×1`.
- Угловая модель с геометрией, аналогичной `roof-side-corner`.
- Скаты направлены внутрь и вниз.
- Соединяется по тому же принципу, что и `roof-side-corner`.
- Используется для формирования внутренних углов кровли.

### 2. Результаты практических проверок

| Соединение | Результат |
|---|---|
| `roof-side` + `roof-side` | Идеальное соединение |
| `roof-side` + `roof-side-corner` | Хорошее соединение |
| `roof-side-corner` + `roof-side-corner` | Хорошее соединение |
| 4 × `roof-side-corner` | Получается замкнутая соединённая конструкция |

### 3. Прямое соединение `roof-side`

Два элемента `roof-side`, расположенные рядом, идеально стыкуются.

Результат:
- зазоров между элементами нет;
- скаты соединяются аккуратно;
- дополнительная подгонка не требуется.

**Решение:** `roof-side` можно использовать для формирования непрерывных прямых участков низкой кровли.

### 4. Соединение прямого и углового элементов

Проверено соединение:

- `roof-side`
- `roof-side-corner`

Результат: элементы хорошо соединяются между собой.

**Решение:** модели совместимы и могут использоваться вместе при формировании кровли.

### 5. Соединение угловых элементов

Проверено соединение двух соседних элементов `roof-side-corner`.

Результат: элементы хорошо соединяются между собой.

Дополнительно проверена конструкция из четырёх `roof-side-corner`.

Результат:
- четыре элемента соединяются между собой;
- получается замкнутая конструкция;
- дополнительные соединительные детали не требуются.

**Решение:** `roof-side-corner` подходит для формирования замкнутых контуров низкой кровли.

### 6. Внутренний угловой элемент

`roof-side-corner-inner` имеет такие же габариты, как `roof-side-corner`.

Основное отличие заключается в направлении скатов:
- у `roof-side-corner` скаты направлены наружу вниз;
- у `roof-side-corner-inner` скаты направлены внутрь вниз.

Элемент соединяется по тому же принципу, что и обычный угловой элемент.

**Решение:** использовать `roof-side-corner-inner` для формирования внутренних углов и более сложных конфигураций низкой кровли.

### 7. Итог по низкой кровельной группе

Совместимость основных элементов низкой кровельной группы подтверждена практическими проверками в Unity.

Установлено:
- прямые элементы `roof-side` идеально соединяются между собой;
- прямые и внешние угловые элементы совместимы;
- соседние внешние угловые элементы совместимы;
- четыре внешних угловых элемента образуют замкнутую конструкцию;
- внутренний угловой элемент имеет совместимые габариты и принцип соединения с внешним угловым элементом.

**Вывод:** низкая кровельная группа пригодна для модульной сборки кровель с прямыми участками, внешними и внутренними углами.

Проверка высокой кровельной группы (`roof-high`) ещё не проводилась.

# Результаты сборки первого тестового дома

## 1. Общая концепция

Первый тестовый дом собирается из модульных кубических блоков размером `1×1×1`.

Конфигурация:

- Первый этаж: 3 стеновых блока, расположенных Г-образно.
- Второй этаж: 2 стеновых блока над двумя клетками первого этажа.
- Третья клетка второго этажа остаётся открытой.
- Крыша: 2 модуля `roof`, по одному над каждому блоку второго этажа.

Итого:
- 5 стеновых блоков.
- 2 модуля крыши.

Такая конструкция позволяет получить небольшой двухэтажный дом с выразительным силуэтом и открытой частью второго этажа.

## 2. Использованные модели

### Первый этаж

- `wall-window` ×2
- `wall-door` ×1

### Второй этаж

- `wall-paint-window` ×2

### Крыша

- `roof` ×2

В одном здании допускается и приветствуется смешивание разных вариантов стен.

Например:
- окна на первом этаже;
- дверь на фасаде;
- другой цвет или текстура стен на втором этаже.

Модели с суффиксом `-paint` позволяют разнообразить внешний вид без изменения основной геометрии.

## 3. Точные Transform тестового дома

Все стеновые блоки и крыши используют Scale `(1, 1, 1)`, если не указано иное.

### Первый этаж

| Объект | Position | Rotation |
|---|---|---|
| `wall-window-1` | `(0, 0, 0)` | `(0, 90, 0)` |
| `wall-window-2` | `(1, 0, 0)` | `(0, -90, 0)` |
| `wall-door` | `(0, 0, 1)` | `(0, 90, 0)` |

### Второй этаж

| Объект | Position | Rotation |
|---|---|---|
| `wall-paint-window-1` | `(0, 1, 0)` | `(0, 0, 0)` |
| `wall-paint-window-2` | `(1, 1, 0)` | `(0, 0, 0)` |

### Крыша

| Объект | Position | Rotation |
|---|---|---|
| `roof-1` | `(0, 2, 0)` | `(0, 90, 0)` |
| `roof-2` | `(1, 2, 0)` | `(0, 90, 0)` |

Крыши соединяются без заметного шва. Их высота и пропорции визуально хорошо сочетаются с двухэтажной конструкцией.

## 4. Деревянный каркас — `structure-poles`

### Назначение

`structure-poles` принят как стандартный декоративный элемент для кубических стеновых блоков Village.

Модель содержит четыре деревянных столба, формирующих каркас вокруг одного кубического блока.

### Проверенное размещение

- Один объект `structure-poles` на один кубический стеновой блок.
- Position совпадает с Position соответствующего стенового блока.
- Scale: `(1.01, 1, 1.01)`.

### Причина изменения Scale

При исходном размере деревянные элементы внутри `structure-poles` мерцали из-за Z-fighting между собственными поверхностями.

Небольшое увеличение по X и Z до `1.01` устранило мерцание.

При этом:
- каркас сохраняет правильные пропорции;
- деревянные элементы не конфликтуют с крышей;
- каркас аккуратно соединяется с соседними модулями.

### Стыки соседних модулей

При размещении `structure-poles` на соседних блоках некоторые деревянные элементы повторяются на общем стыке, образуя двойную доску.

Результат проверен визуально в Unity. Повторение выглядит логично и воспринимается как намеренная архитектурная деталь.

**Решение:** не устранять повторяющиеся доски на стыках. Считать их частью внешнего вида деревянного каркаса.

## 5. Выводы по архитектуре домов Village

### Основной строительный модуль

Для основной массы зданий использовать объёмные стеновые блоки размером `1×1×1`.

Разные варианты `wall` можно смешивать в одном здании, чтобы создавать разнообразные фасады.

`wall-pane` оставить преимущественно для плоских конструкций, перегородок и других случаев, где не требуется полноценный объёмный блок.

### Архитектурный силуэт

Дома не должны выглядеть как одинаковые кубические коробки.

Разнообразие планируется получать за счёт:
- разного количества и расположения модулей;
- разной этажности;
- комбинаций стен с окнами и дверями;
- сочетания разных текстур;
- различных вариантов крыш;
- деревянного каркаса и дополнительных архитектурных деталей.

### Обязательные и дополнительные элементы

При проектировании Prefab необходимо разделять:

**Основные архитектурные элементы:**
- стеновые блоки;
- крыши;
- деревянный каркас;
- детали, формирующие силуэт и конструкцию здания.

**Дополнительный декор:**
- предметы возле дома;
- бочки и ящики;
- лестницы и другие небольшие детали;
- элементы окружения.

Основные элементы должны входить в Prefab здания. Дополнительный декор можно будет добавлять отдельно, в том числе процедурно через будущую систему визуального оформления биома.
