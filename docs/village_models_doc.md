# Kenney Retro Medieval Kit — документация моделей Village

## 1. Общая информация

- Всего моделей: 105
- Анимаций: 0
- Лицензия: CC0 1.0 Universal
- Текстуры: отдельная папка `Textures`
- Форматы исходных моделей: OBJ, GLB, FBX

Набор используется для создания архитектуры биома Village в TinyLands.

Основная задача — сборка полноценных зданий из модульных частей с различающейся архитектурой и силуэтами.

# 3. Проверенные параметры моделей

## 3.1. Стены и фасады

| Модель | Размер | Примечание |
|---|---|---|
| `wall` | 1×1×1 | Объёмная стена |
| `wall-pane` | 1×1×0 | Плоская стена, Pivot в центре основания |
| `wall-window` | 1×1×1 | Collider охватывает модель |

Дополнительные наблюдения:

- Стандартные грани `wall` выглядят одинаково.
- Модель `wall-pane` имеет плоскую геометрию.
- Модели хорошо совмещаются между собой.

## 3.2. Кровельные модели

| Модель | Размер | Примечание |
|---|---|---|
| `roof` | 1×1×1 | Pivot в центре основания |
| `roof-side` | 1×0.5×1 | Один скат, модель усечена с трёх сторон |
| `roof-side-corner` | 1×0.5×1 | Угловая модель, два ската вниз в стороны, две усечённые стороны |
| `roof-side-corner-inner` | 1×0.5×1 | Внутренний угловой элемент, скаты направлены внутрь и вниз |
| `roof-high-side` | 1×1×1 | Высокий кровельный элемент с одним скатом |
| `roof-high-side-corner` | 1×1×1 | Высокий угловой элемент с двумя скатами |
| `roof-high-side-corner-inner` | 1×1×1 | Высокий внутренний угловой элемент |

Модель `roof-high` отсутствует в наборе.

### Проверка соединений низкой кровли

| Соединение | Результат |
|---|---|
| `roof-side` + `roof-side-corner` | Успешно |
| Два соседних `roof-side-corner` | Успешно |
| Четыре `roof-side-corner` | Образуют замкнутую конструкцию |
| `roof-side-corner-inner` + `roof-side` | Успешно |
| `roof-side-corner-inner` + `roof-side-corner` | Успешно |

Дополнительные наблюдения:

- `roof-side-corner-inner` имеет те же габариты, что и `roof-side-corner`.
- Основное отличие — направление скатов внутрь и вниз.
- Внутренний угол соединяется по той же логике, что и обычный угловой элемент.

### Проверка соединений высокой кровли

Все модели высокой кровельной группы имеют размер 1×1×1.

| Соединение | Результат |
|---|---|
| `roof-high-side` + `roof-high-side-corner` | Успешно |
| Два соседних `roof-high-side-corner` | Успешно |
| Четыре `roof-high-side-corner` | Образуют замкнутую конструкцию |
| `roof-high-side-corner-inner` + `roof-high-side` | Успешно |
| `roof-high-side-corner-inner` + `roof-high-side-corner` | Успешно, сочетание выглядит эстетично |

Дополнительные наблюдения:

- Габариты высокой кровли идеально подогнаны.
- Прямые и угловые элементы совместимы.
- Внутренний угол совместим с прямым и внешним угловым элементами.
- Замкнутая конструкция из четырёх внешних угловых элементов собирается успешно.

## 3.3. Башни

Все модели башенной группы имеют шестиугольную форму.

| Модель | Размер | Назначение |
|---|---|---|
| `tower` | 1×1×1 | Основной корпус башни |
| `tower-base` | 1.1×1×1.1 | Основание башни, расширяется книзу |
| `tower-edge` | 1.2×0.4×1.2 | Промежуточный выступающий пояс |
| `tower-top` | 1.2×0.3×1.2 | Верхняя завершающая деталь |

### Проверенная последовательность сборки

Снизу вверх:

1. `tower-base`
2. `tower`
3. `tower-edge`
4. `tower-top`

Результат: все элементы хорошо соединяются, получается цельная конструкция башни.

Дополнительные наблюдения:

- `tower-edge` располагается между корпусом и верхушкой.
- Основание немного расширяется книзу.
- Верхние детали выступают за габариты основного корпуса.

Модели `tower-paint` и `tower-paint-base` пока отдельно не проверялись.

## 3.4. Зубчатые навершия стен — Battlement

Группа состоит из каменных прямоугольных элементов с зубьями, предназначенных для оформления верхней части крепостных стен.

| Модель | Размер | Назначение |
|---|---|---|
| `battlement` | 1×0.4×0.3 | Прямой зубчатый элемент |
| `battlement-corner-inner` | 1×0.4×1 | Внутренний угол стены |
| `battlement-corner-outer` | 1×0.4×1 | Внешний угол стены |
| `battlement-half` | 0.5×0.4×0.3 | Половинный прямой элемент |

### Проверенные соединения

| Соединение | Результат |
|---|---|
| Два `battlement` подряд | Успешно |
| `battlement` + `battlement-corner-outer` | Успешно |
| `battlement` + `battlement-corner-inner` | Успешно |
| `battlement-half` + `battlement` | Успешно |

Дополнительные наблюдения:

- Рисунок зубцов `battlement-half` совпадает с обычным `battlement`.
- Прямые и угловые элементы соединяются без проблем.
- Группа проверена на основные соединения.

## 3.5. Полы и лестницы

### Напольные элементы

| Модель | Размер | Особенности |
|---|---|---|
| `floor` | 1×0.05×1 | Тонкая напольная платформа, поверхность немного выше `floor-flat` |
| `floor-flat` | 1×0×1 | Плоская поверхность без толщины |

При одинаковом положении `floor` находится немного выше `floor-flat`.

`floor-flat` идеально ложится под другие элементы и является предпочтительной базовой поверхностью для большинства лестничных элементов.

### Лестничные напольные элементы

| Модель | Размер | Особенности |
|---|---|---|
| `floor-stairs` | 1×0.35×1 | Хорошо сочетается с `floor` и `floor-flat` |
| `floor-stairs-corner-inner` | 1×0.2×1 | Хорошо сочетается с `floor-flat`, плохо с `floor` |
| `floor-stairs-corner-outer` | 1×0.2×1 | Хорошо сочетается с `floor-flat`, плохо с `floor` |

### Ступенчатые элементы

| Модель | Размер | Особенности |
|---|---|---|
| `floor-steps` | 1×0.2×1 | Хорошо сочетается с `floor-flat`, плохо с `floor` и `floor-stairs` |
| `floor-steps-corner-inner` | 1×0.2×1 | Хорошо сочетается с `floor-flat`, плохо с `floor` |
| `floor-steps-corner-outer` | 1×0.2×1 | Хорошо сочетается с `floor-flat`, плохо с `floor` |

### Самостоятельные лестницы

| Модель | Размер | Особенности |
|---|---|---|
| `stairs-corner` | 1×0.35×1 | Угловая лестница, хорошо сочетается с `floor` и `floor-flat` |
| `stairs-stone` | 1×1×1 | Каменный лестничный пролёт |
| `stairs-wood` | 1×1×1 | Деревянный лестничный пролёт |

Дополнительные наблюдения:

- `stairs-stone` и `stairs-wood` имеют одинаковую геометрию и отличаются текстурой.
- Совместимость `stairs-stone` и `stairs-wood` с другими элементами отдельно не проверялась.
- `floor-flat` является предпочтительной базовой поверхностью для большинства угловых ступенчатых элементов.
- `floor` и `floor-flat` не взаимозаменяемы без учёта высоты.

# 4. Деревянный каркас

## 4.1. Structure-poles

`structure-poles` проверен на соседних модулях.

Для эксперимента был изменён Scale модели.

Результат:

- Элементы хорошо совмещаются между соседними модулями.
- В месте соединения появляется повторяющаяся двойная доска.
- Повторение выглядит логично и эстетично.
- `structure-poles` можно использовать как стандартный декоративный элемент для кубических блоков Village.

Изменённый Scale зафиксирован в рабочей сцене; точное значение необходимо сверять с актуальной настройкой Unity перед использованием в Prefab.

# 5. Общие правила работы с моделями

- Стандартный Scale моделей: `(1, 1, 1)`.
- Большинство моделей имеют размер `1×1×1`.
- Модели с суффиксом `-pane` имеют размер `1×1×0`.
- Некоторые архитектурные элементы имеют нестандартные габариты.
- Не все элементы взаимозаменяемы.
- Совместимость проверяется практическим размещением моделей в Unity.
- Повторно проверять каждую стандартную модель не требуется.
- Необычные модели проверяются отдельно.
- Перед созданием Prefab необходимо учитывать результаты проверки соединений.
